## 1. Doctrina de Coberturas: El Modelo "Tailored Baseline"

En Manto 2.0, **toda mascota asegurada (sea perro o gato, criollo o de raza)** cuenta de manera automática con un **Paquete Base de Coberturas Mínimas Garantizadas**, diseñado para proteger contra las contingencias médicas más críticas y costosas (accidentes súbitos, urgencias vitales y diagnóstico).

A partir de esta base esencial:
1. Se aplican **sublímites fenotípicos específicos** adaptados a las vulnerabilidades genéticas de cada raza.
2. Si la raza es de manejo especial según la **Ley 1801 de 2016**, se anexa forzosamente la cobertura de **Responsabilidad Civil Extracontractual (50 SMLMV)**.
3. El asegurado personaliza su plan sumando **Add-ons Modulares** (enfermedades, medicamentos, telemedicina, exequial, guardería).

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       ARQUITECTURA DE PROTECCIÓN MANTO                      │
│                                                                             │
│   [ + ADD-ONS MODULARES A ELECCIÓN ]  (Enfermedades, Medicamentos, etc.)    │
│   ▲                                                                         │
│   [ + RCE LEY 1801 OBLIGATORIA ]      (Solo para 15 razas de manejo especial│
│   ▲                                                                         │
│   [ SUBLÍMITES FENOTÍPICOS POR RAZA ] (BOAS, IVDD, Displasia, HCM, etc.)    │
│   ▲                                                                         │
│   ═══════════════════════════════════════════════════════════════════════   │
│   COBERTURAS MÍNIMAS BASE GARANTIZADAS (Accidentes + Urgencias + Diagnóstico│
└─────────────────────────────────────────────────────────────────────────────┘
```

## 7. Descuentos y Modificadores Actuariales

La prima mensual final en Pesos Colombianos (COP) resulta de multiplicar la tarifa base por los modificadores acumulativos:

1. **Descuento por Esterilización**: **$-5\%$** ($0.95$) aplicable a cualquiera de las 43 razas.
2. **Selección de Deducible**:
   * **10% de copago**: Factor **$1.15$** (+15% en prima).
   * **15% de copago**: Factor **$1.00$** (Tarifa estándar).
   * **20% de copago**: Factor **$0.88$** (-12% de descuento en prima).
3. **Descuento por Frecuencia Anual**: **1 mes gratis al año** (se cobran 11 meses en lugar de 12).
